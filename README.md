# Impacto de las Redes Sociales en la Productividad y el Bienestar

Este proyecto analiza como el uso diario de redes sociales y otros hábitos digitales influyen en la productividad,
el estrés, el sueño y la satisfacción laboral, utilizando un conjunto de datos de 30,000 registros.

## Objetivo

Explorar el impacto del tiempo en redes sociales, notificaciones y otros factores digitales en al productividad y el 
bienestar de los trabajadores y desempleados, segmentando por edad, género y tipo de trabajo.

## Técnicas Utilizadas

- Análisis exploratorio (EDA)
- Limpieza de datos
- Visualización de datos

# Tecnologías

- Python 3.12
- Pandas
- Matplotlib
- Seaborn
